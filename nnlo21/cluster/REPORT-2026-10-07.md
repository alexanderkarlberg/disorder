## Bugs found (not fixed; fixes are for thA371a)
1. **Crash in `nlo31`, `kt_jets` (called from `zeus_jets` ← `accept_zeus` ← `real_evalv`):**
   - With NaN momenta (a degenerate mapped configuration), no pair is selected, so `ii = 0` with `beam = .true.`.
   - The code then writes to `act(0)`, which corrupts the heap and aborts with "double free or corruption".
   - It is reproducible; about 16 seeds are left out (e.g. B r seed 4711).
   - Proposed fix: treat `ii == 0` or non-finite momenta as a failed event.
2. **Latent bug, `nlo31.f90:625`:** `hcacc(160) += sg*w*wgt` with `sg(150)` in mode 2. It reads past the end of `sg` and writes only to unused cells, so the results are fine, but bounds-checked runs fail.
3. **TECHMIN/TECHDIFF act only in `nlo31` part r.** The lo, vi and kp parts ignore them, so a "TECHDIFF correction" of D (part lo) is zero by construction.
